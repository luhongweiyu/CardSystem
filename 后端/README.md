# 卡密系统后端

Go、Gin、GORM、MySQL 服务，提供独立的点卡和时长卡业务。

## 运行

1. 在 `config.yaml` 配置数据库和监听端口。
2. 执行 `go run .`。服务会创建或补充表结构；旧数据迁移需另行启用，见下文。
3. 管理端静态文件可放在 `assets`；也可只运行 API。

服务支持 HTTP。接口签名不加密网络流量，生产环境应限制管理端和数据库的网络访问。

## 数据边界

- 点卡余额保存在 `point_card_<管理员名>`；设备会话和余额流水分别保存在 `point_device_session`、`point_ledger`。
- 时长卡保存在 `duration_card_<管理员名>`，使用固定时长和到期时间，不读取点卡余额。
- `duration_recharge_card` 保存时长充值卡；代理账号及余额保存在 `agent_account`。
- 旧表 `card_<管理员名>` 只用于迁移，不参与正式业务查询。`AutoMigrate` 不导入旧业务数据。

代理余额变动日志写入 `log/代理账号<ID>_YYYYMM`，字段以 Tab 分隔，包含变更后余额、变动金额、原因和业务信息。点卡自身流水写入 `point_ledger`。

## 旧时长卡迁移

在 `config.yaml` 设置 `迁移: true` 后启动服务，才会迁移来源表 `card_<管理员名>`。仅迁移目标时长卡表不存在的管理员；成功后来源表改名为 `_bak`，已有备份不会覆盖。迁移后将开关改回 `false`。

迁移前备份数据库并停止旧服务。价格、`visitor_recharge`、点卡会话和点数流水不迁移；遇到表、密码、卡密或代理映射冲突时会停止处理。

## 配置

| 配置项 | 用途 |
| --- | --- |
| `网站.端口` | 服务监听端口，默认 `802` |
| `网站.可信代理` | 可提供真实客户端 IP 的反向代理地址 |
| `api.每小时请求上限`、`api.最大请求字节` | 请求频率和请求体限制 |
| `迁移` | 是否执行旧时长卡迁移，默认 `false` |
| `心跳缓存.同步间隔分钟` | 心跳缓存同步到数据库的间隔 |
| `管理员注册.启用` | 是否开放管理员注册 |

自动离线时间和时长卡暂停扣除分钟数在软件设置中配置。
