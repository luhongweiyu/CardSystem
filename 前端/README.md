# 卡密系统前端

前端使用 Vue 3、Vite、Pinia 和 Element Plus，包含管理员/代理账号管理端和卡密查询页。点卡和时长卡分别管理，
页面不会把两种卡密混在同一张表中。

## 开发与构建

```sh
npm install
npm run dev
npm run build
```

开发服务器把 `/admin`、`/agent`、`/card`、`/duration` 和访客 API 代理到 `http://127.0.0.1:802`。生产环境默认请求当前站点的同源
API，也可以用 `VITE_API_BASE_URL` 指定独立 API 地址。

系统支持 HTTP，不要求客户端必须支持 HTTPS。若使用 HTTP，建议开启后端接口口令校验并限制管理端的网络暴露范围；该校验
不提供加密，也不能阻止链路上的窃听或重放。

## 页面说明

- **点卡**：按软件和点数生成卡密，支持指定卡密、批量冻结/解冻/删除、备注和配置编辑、管理员手工补扣点，以及导出当前
  页。
- **时长卡**：按软件和固定分钟数生成独立时长卡，支持最晚激活、查询、冻结/解冻、续费、删除和详情查看。
- **软件管理**：设置默认授权时长、心跳间隔、自动离线时间和多个点卡计费方案；授权时长统一按分钟设置（5 分钟至 3 天），默认授权时长必须对应一个启用方案，授权时长按已配置
  方案执行。管理员可创建、设置、充值或删除代理账号。
- **点数流水**：分页查看所有真实余额变化。每行包含时间、卡密、软件、增减、变动前后余额和备注；扣费备注中包含设备
  ID/别名快照。
- **卡密查询页**（`/usercard/index.html`）：明确选择点卡或时长卡模式；点卡显示余额、设备和流水，时长卡显示激活状态与到期时间。
- `/visitor/index.html?center_id=...` 为旧访客入口，暂时保留兼容；管理端的查询链接统一指向卡密查询页。

点卡和时长卡客户端登录、心跳和退出的完整参数约定见 [点卡API.md](../后端/点卡API.md)。
