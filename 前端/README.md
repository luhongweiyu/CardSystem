# 卡密系统前端

前端使用 Vue 3、Vite、Pinia 和 Element Plus，包含管理员/代理账号管理端和卡密查询页。点卡和时长卡分别管理，
页面不会把两种卡密混在同一张表中。

## 开发与构建

```sh
npm install
npm run dev
npm run build
```

开发服务器把 `/admin`、`/agent`、`/point_card`、`/duration_card` 和访客 API 代理到 `http://127.0.0.1:802`。生产环境默认请求当前站点的同源
API，也可以用 `VITE_API_BASE_URL` 指定独立 API 地址。

管理端的 `/card`、`/duration-card` 等是前端页面路由，不是服务端接口；客户端接口必须使用 `/point_card/*` 或 `/duration_card/*`。
旧客户端使用的 `/card/*`、`/duration/*` 不属于本版本接口。

系统支持 HTTP，不要求客户端必须支持 HTTPS。若使用 HTTP，建议开启后端接口口令校验并限制管理端的网络暴露范围；该校验
不提供加密，也不能阻止链路上的窃听或重放。

## 页面说明

登录页记住上次成功登录的身份，放大对应按钮，回车默认使用该身份。密码不写入 Cookie 或本地存储，可使用浏览器密码管理器填充。有效登录令牌仅保存在当前标签页的 `sessionStorage` 中，刷新页面可继续使用；到期或接口确认失效时返回登录页，不自动重试业务操作。主动退出会清除本地会话并请求服务端撤销令牌。

- **点卡**：按软件和点数生成卡密，支持 0 点卡、指定卡密、批量冻结/解冻/删除、批量设置账户代扣、备注和配置编辑、管理员手工补扣点、设备详情与下线、点数流水以及导出当前页。下线保留未到期授权，不是封禁。
- **时长卡**：按软件和固定分钟数生成独立时长卡，支持最晚激活、查询、冻结/解冻、续费、删除、暂停状态查看和详情查看；管理员与小伙伴都能管理自己有权限的卡密。
- **时长充值卡**：按软件、每次增加分钟数和使用次数生成充值卡，支持管理员/小伙伴查询、编辑、冻结、删除和查看使用记录。
- **软件管理**：设置默认授权时长、心跳间隔、自动离线时间、时长卡暂停扣除分钟数和多个点卡计费方案；授权时长统一按分钟设置（15 分钟至 30 天），默认授权时长必须对应一个启用方案，授权时长按已配置
  方案执行。管理员可创建、设置、充值或删除代理账号，并维护时长卡价格锚点。
- **点数流水**：分页查看所有真实余额变化。每行包含时间、卡密、软件、增减、变动前后余额和备注；扣费备注中包含设备
  ID/别名快照。
- **卡密查询页**（`/usercard/index.html`）：明确选择点卡或时长卡模式；点卡显示余额、设备和流水，时长卡显示激活状态、暂停余额、到期时间，并可使用充值卡或执行暂停/恢复。
- `/visitor/index.html?center_id=...` 为旧访客入口，暂时保留兼容；管理端的查询链接统一指向卡密查询页。

管理员可在软件编辑中允许点卡授权复用；客户端还需明确请求优先复用，才会接手同卡离线设备的未到期授权。

点卡和时长卡客户端登录、心跳和退出的参数约定见 [卡密API.md](../后端/卡密API.md)。
